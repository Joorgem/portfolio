# Guia para Criação de Mídia - Seção Projects (Minimalista)

## 📂 Estrutura de Arquivos

Coloque todos os arquivos de mídia em: `public/assets/projects/`

### Arquivos Necessários para o SOLTO:

#### GIFs (Essenciais - Design Minimalista)
- `solto-demo.gif` - Demonstração limpa da loja (navegação, produtos, checkout)
- `solto-admin.gif` - Painel administrativo (dashboard, produtos, pedidos)

#### Vídeos (Opcional - para Modal)
- `solto-features.mp4` - Funcionalidades técnicas detalhadas
- `solto-video-thumb.jpg` - Thumbnail minimalista

## 🎥 Especificações Técnicas

### Para GIFs:
- **Resolução**: 1920x1080 (Full HD) ou 1280x720 (HD)
- **Duração**: 10-30 segundos ideal
- **Tamanho**: Máximo 10MB por GIF
- **Frame rate**: 15-24 fps
- **Formato**: .gif otimizado
- **Loops**: Infinito

### Para Vídeos:
- **Resolução**: 1920x1080 (Full HD)
- **Duração**: 30-60 segundos ideal
- **Formato**: .mp4 (H.264)
- **Tamanho**: Máximo 50MB
- **Bitrate**: 3-5 Mbps

### Para Imagens:
- **Resolução**: Mínimo 1200x800
- **Formato**: .jpg ou .webp
- **Qualidade**: Alta (90-95%)
- **Tamanho**: Máximo 2MB cada

## 🛠️ Ferramentas Recomendadas

### Para Gravação de Tela:
- **OBS Studio** (Gratuito) - Melhor para gravações longas
- **LICEcap** (Gratuito) - Simples para GIFs curtos
- **ScreenToGif** (Gratuito) - Específico para GIFs
- **Loom** (Pago/Gratuito) - Online, fácil de usar

### Para Otimização:
- **GIMP** - Otimizar GIFs
- **FFmpeg** - Converter/comprimir vídeos
- **TinyPNG** - Comprimir imagens

## 📋 Roteiro de Gravação Minimalista

### GIF 1: solto-demo.gif (Loja - Fluxo Limpo)
**Duração: 15-20 segundos**

1. **Homepage**: Página inicial com produtos (3s)
2. **Navegação**: Scroll suave pelos produtos (3s)
3. **Produto**: Clicar e ver detalhes limpo (3s)
4. **Carrinho**: Adicionar e abrir carrinho (2s)
5. **Checkout**: Tela de checkout (3s)
6. **Finalização**: Sucesso/retorno (2s)

### GIF 2: solto-admin.gif (Admin - Dashboard Foco)
**Duração: 12-15 segundos**

1. **Dashboard**: Métricas principais (3s)
2. **Produtos**: Gestão de produtos (4s)
3. **Pedidos**: Lista de pedidos (3s)
4. **Edição**: Editar produto rapidamente (3s)
5. **Retorno**: Dashboard final (2s)

## 🎯 Filosofia Minimalista

### Princípios de Gravação:
- **Foco**: Mostre apenas funcionalidades essenciais
- **Fluidez**: Movimentos suaves e naturais
- **Clareza**: Interface limpa, sem elementos desnecessários
- **Ritmo**: Pausas estratégicas para absorção

### Qualidade Visual:
- Capture com interface real (dados reais)
- Evite cursores grandes demais
- Mantenha consistência de timing
- Use transições naturais
